# Subjects

This map lists the subjects of this Mnemorph instance. Each subject folder's `README.md` is its overview and first reading. Follow a link for the question it helps answer; a known document can be read directly. Reading an overview does not activate every linked method or make historical instructions current.

- [Core](../src/core/__entry__.md) holds the shared methods from Mnemorph-Core and explains how work, judgment and memory relate. Start there to see how Mnemorph operates and learns.
- [Personal](personal/README.md) holds the user's own life. It is private and applies when a task touches their life.
- [Settings](settings.md) holds this instance's standing rules that adjust Core defaults. Read it before following a default it may change.
- [Inbox](inbox.md) queues what the user said today until reflection files it into its subjects.
- [Record](record/README.md) keeps the user's own words, verbatim, as the authority on what they said. It is not loaded by default.

When a new subject begins, such as a writing practice, a research field or a project, give it a folder under `src/` with a `README.md` overview and add a line here. Keep domain material in its subject and shared methods in Core.

The [helper](../tools/README.md) supports discovery and reproducible selections.
