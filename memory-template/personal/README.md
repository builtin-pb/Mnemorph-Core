# Personal

This is the user's personal account: everyday context that spares them repeating themselves. Consult it for their own life, without colouring unrelated work; "How they like help" applies to every task. [Personalize](../../src/core/memory/personalize.md) starts and extends it from material the user offers.

It is private. Never publish it, copy it into a public repository or offer it upstream to Mnemorph-Core; push it only to a remote confirmed to be private. Record what the user wants remembered, within the limits they set; credentials, recovery codes and other secrets always stay out. Relevant facts about close people belong too, attributed to their source. Date what can change, cite sources, mark inferences and let the user's later direct statements win.
