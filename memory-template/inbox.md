# Inbox

A same-day queue, not a store: reflection files each note into its subject and removes it. Agents append without review.

Append one line per note: date and time, host and session id, kind (fact, preference or correction; a hint, not a verdict), and the user's words in quotes, with a few words of context if the words alone are unclear. Note only what the user said in the current session. Never note agent text, test or evaluation prompts, or a bare acceptance such as "ok" or "as you recommend" as the user's words. Keep secrets out, and commit only this file.
